# Yee Peng Chiang Mai — Virtual Experience (ยี่เป็ง เชียงใหม่)

[![Language: Thai](https://img.shields.io/badge/Language-Thai-orange.svg)](#)
[![Language: English](https://img.shields.io/badge/Language-English-blue.svg)](#)

**Yee Peng Chiang Mai** is a high-fidelity, interactive web experience designed to showcase the beauty, history, and traditions of the Yee Peng Festival (Lanna's Festival of Lights) in Chiang Mai, Thailand.

---

## 🌟 Features (คุณสมบัติเด่น)

-   **Cinematic Immersive Experience**: Immersive hero animations using HTML5 Canvas and advanced CSS 3D perspectives.
-   **Interactive 3D History Book**: A custom-built 3D flipping book that tells the story of Yi Peng from its Hariphunchai roots to the present day.
-   **Multi-Language Support (i18n)**: Full localization in **Thai** and **English** with a seamless toggle system.
-   **Virtual Activities**: Interactive modules for releasing virtual lanterns, Phang Pratheep, and Krathongs.
-   **Cultural Timeline**: A structured vertical chronicle of Lanna history and the evolution of the festival.
-   **Responsive Design**: Optimized for both desktop and mobile devices with a premium "Manuscript" aesthetic.
-   **Atmospheric Gallery**: An auto-scrolling infinite carousel and a high-resolution lightbox for festival photography.

---

## 📂 Project Structure (โครงสร้างโปรเจกต์)

-   `index.html`: The main landing page with an atmospheric parallax intro and core festival highlights.
-   `festival.html`: In-depth history, the 3D Interactive Book, and the Chronicle timeline.
-   `lanterns.html`: Exploration of Lanna lanterns and interactive release simulation.
-   `traditions.html`: Cultural rituals, etiquette, and the spirit of Lanna.
-   `gallery.html`: A visual journey through the festival with an immersive photo collection.
-   `game.html`: The virtual experience module for interactive festival participation.
-   `member.html`: Information about the development team.
-   `css/`: Modular stylesheets (main.css, animations.css, member.css, etc.).
-   `js/`: Functional logic (app.js, i18n.js, hero.js, parallax.js, etc.).
-   `assets/`: Visual assets including high-impact imagery and the YIPENG logo.

---

## 🛠 Technology Stack (เทคโนโลยีที่ใช้)

-   **Structure**: HTML5 (Semantic Elements)
-   **Styling**: Vanilla CSS3 (Custom Properties, 3D Transforms, Flexbox/Grid)
-   **Logic**: Pure JavaScript (ES6+)
-   **Graphics**: HTML5 Canvas API for atmospheric particle and lantern systems.
-   **Localization**: Custom-built i18n system for dynamic content swapping.
-   **Typography**: Google Fonts (Kodchasan, Nunito).

## 🚀 Getting Started (เริ่มต้นใช้งาน)

This is a front-end project and does not require a backend server for basic functionality.

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/thanapdev/Yee-Peng-CNX.git
    ```
2.  **Open the project**:
    Simply open `index.html` in any modern web browser.
3.  **Language Toggle**:
    Use the **TH/EN** toggle in the navigation bar to switch languages.
